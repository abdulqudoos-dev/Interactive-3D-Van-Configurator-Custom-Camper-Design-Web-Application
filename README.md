# Interactive 3D Van Configurator

> **Built by [Abdul Qudoos](https://www.abdul-qudoos.com)**, AI Automation & Forward Deployed Engineer · [More projects](https://www.abdul-qudoos.com/work)

A browser-based 3D configurator for designing a custom camper van interior. Users place and arrange furniture, including beds, bunks, cabinets, tables, chairs, a sink, a stove and a toilet, inside a 3D van model, and switch between preset camera views.

- **3D:** Three.js with React Three Fiber, Drei and post-processing; GLB models and an HDR environment
- **UI:** React, Vite, MUI, Framer Motion and React Spring
- **State:** Zustand

The app lives in [`Van-Configurator-3D/`](Van-Configurator-3D/).

## Run it

```bash
cd Van-Configurator-3D
npm install
npm run dev
```
